# 《工位上的新同事》

一部关于大模型如何改变职场的现实主义中长篇小说（章节连载）。

> 暂定名，欢迎随时改名。

## 基本信息

- **类型**：现实主义职场小说
- **主题**：大模型（LLM）对普通职场人的冲击与重塑
- **视角**：第三人称限知，跟随主角林澈
- **主角**：林澈，24 岁，硕士应届，广告算法工程师（流量策略方向），日常与大模型的接触仅限写代码时调 API，梦想是转岗到公司的大模型部门「星语实验室」
- **公司**：星潮科技——以信息流广告为主业的互联网公司，内部有自研大模型「星语」及星语大模型实验室
- **篇幅**：每章 3000–4000 字，暂定 12–16 章
- **进度**：第 1、2 章已完成（v2 重构版），已推送

## 协作方式

1. 每完成一章，推送到本私有仓库（`main` 分支）。
2. 你阅读后给出微调意见（人物、情节、细节、风格皆可）。
3. 我按反馈修改已推送章节或调整后续走向，再继续写下一章。
