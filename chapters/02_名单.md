# 第二章 名单

转岗通道关闭一周后的那个星期二早上，林澈到工位时，那封邮件已经躺在钉钉里了。发件人：人力资源部。主题：《关于星语实验室第二批内部转岗初筛名单的确认通知》。

他深吸一口气，点开。

附件是一张表，三列：姓名、部门、初筛评级。他在第十七行找到了自己——林澈，算法部·流量策略组，A-。名单末尾附了一行小字：请以上同事于本周五前完成《转岗意向确认书》签署，逾期视为自动放弃。

林澈把表格从上看到下，又从头看了一遍。四十七个人，几乎全是入职不满两年的年轻人，二十几个部门，每个部门两三个。他数了数算法部的名字：他自己，加上隔壁组的许薇——一共两个。苏晓不在里面，她本来就属于那边。

他关掉邮件，又点开，又关掉。心里说不上是什么滋味。像被选进了什么组织，又像被划进了一个篮子，篮子的标签上写着「可用」。

上午十点，韩铮端着保温杯路过他的工位，瞥了一眼他的屏幕，站住了。

「转岗初筛过了？」他问。

林澈点头，想说什么，又咽了回去。

韩铮像是看出了他的心思，把保温杯放在他桌上，声音不大：「小林，跟你说句实话。实验室不是让你去搞研究的。它就是个人肉 API 池——业务部门把需求扔进去，你们拿星语跑完，挂上实验室的名。真正做前沿的，是那二十个正式研究员。」

「那……你是说，转过去反而……」

「你转过去，你这个工位，会被一个自动化的出价系统顶掉。」韩铮说，「你猜，它顶掉你的速度，快不快。」

林澈没有接话。他盯着保温杯里浮沉的茶叶，第一次觉得，入职培训视频里那句「未来一个人加一个 AI，就是一支完整的团队」，听起来像一句口号，又像一张名单的封皮。

下午两点，算法部临时开会。

马涛站在投影幕布前，身后的 PPT 只写了一页：一张曲线图，横轴是时间，纵轴是人效比，曲线一路向上，标注着「AI 提效专项组成立以来」。

「各位，说点不中听的。」马涛开口，「公司今年的规划，算法部要优化百分之二十的编制。这不是裁员，是结构优化。标准就一条——人效比。我们会综合星语使用率、效果增量、满意度、工龄成本四个维度，按月排名。排名靠后的，进入再培训名单，培训三个月仍无改善的，协商解除。」

会议室里静得能听见空调的风声。有人开始低头翻手机，像是在给自己算账。

马涛顿了顿，补了一句：「这个月，先优化两位。」

散会后，林澈在走廊里碰见陈国栋。陈国栋今年四十五，做广告投放运营做了十五年：看流量、洗流量、压价、抢量，一手「手感」，全公司没人赶得上。他正站在窗边抽烟，看见林澈，招招手。

「小兄弟，转岗初筛过了？」

「嗯。」

「好事。」陈国栋弹了弹烟灰，「年轻人，赶上好时候了。我们那会儿，双十一前三天机房通宵，流量是要抢的。哪像现在，一个模型替你守盘。」他笑了笑，笑纹很深，「别学我，一根筋，把一辈子押在一条流量曲线上。」

林澈想说点什么安慰他，张了张嘴，什么也没说出来。他忽然想起上周五——陈国栋路过他工位，看见他屏幕上那条素材，随口说了一句：「这条活不过明天。」林澈不信，结果第二天下午，那条素材的点击率跳水，果然死了。他当时只觉得神奇，现在才明白，那不是神奇，是十五年的流量泡出来的直觉，是系统里任何一行特征都装不下的东西。

陈国栋拍拍他的肩：「去忙吧。我这烟抽完，也该去收拾东西了。」

下午四点四十分，HR 的同事来叫陈国栋，两个人进了小会议室，门关上。四十五分钟后，陈国栋出来，脸色平静，回到工位，开始收拾东西。他把抽屉里的茶叶、马克杯、一摞泛黄的笔记本装进一个纸箱，动作很慢，像在给自己这十五年打包。

没有人说话。整个 C 区安静得像一潭水，每个人都盯着自己的屏幕，屏幕上的光标一闪一闪，没有人抬头。

韩铮站起来了。

他走到陈国栋工位前，没有说挽留的话，只是伸手帮他扶了扶纸箱里歪倒的马克杯，说：「老陈，路上慢点。」

陈国栋点点头，想了想，又从纸箱里抽出一个深蓝色的硬皮笔记本，递给韩铮：「韩工，流量的家当，留给你做个念想。哪天用不上了，就当废纸卖了。」

韩铮接过来，没有翻开，也没有说「你会用上的」之类的话。他只说：「留着。」

陈国栋抱起纸箱，走到门口，回头看了一眼，说：「韩工，别送了，我还得去接孩子。」

电梯门合上。C 区依然安静。林澈听见隔壁工位有人轻轻吸了一下鼻子，很快又压下去了。

接下来的三天，算法部变得有些不一样了。

第一天，张卫东开始在工位上大声朗读星语生成的实验结论，读到一半，自己先笑了：「你看，连显著性检验都给你写好了，多好。」他原来做特征工程，一个特征要磨半个月，现在他让星语一天出十个「结论」，原封不动交上去，数据一个不改。

第二天，部门群里流传开一份文档，标题是《星语高频提示词模板 100 条》，不知道谁整理的，附了一行字：「各位同事，星语使用率每周统计一次，大家抓紧。」林澈点开看，里面全是些「请用专业口吻」「请加入结论先行」「请结尾升华」之类的指令，像一本写给机器的《报告速成宝典》。

第三天，马涛在部门群里发了一张截图：算法部本周星语使用率 81%，环比提升 57%，全公司第一。「各位，干得漂亮！」后面跟着三个鼓掌的表情。

林澈看着那张截图，想起陈国栋临走那天抱着的纸箱。他想不通，一个人十五年的手感，怎么比不过一个「使用率」的百分比。

那天傍晚，韩铮破天荒地没有下班。他坐在工位上，盯着星语的对话框，屏幕上打了又删，删了又打。林澈加班改报告到八点，路过他身后，忍不住停下来：「韩工，你还没走？」

「小林，」韩铮没回头，「你教教我，这个 prompt，怎么写。」

林澈搬了把椅子坐到旁边。韩铮的屏幕上是星语的对话框，光标停在空白的输入框里，一闪一闪，像他此刻不知道从何说起的十一年。

「你先想，你要它干什么。」林澈尽量放轻声音，「比如……写一份特征重要性分析，你要它当谁，用什么口吻，给谁看。」

韩铮想了很久，一个字一个字地敲：你是一个有十一年广告算法经验的资深工程师，写一份特征重要性分析报告，语气要像跟组里同事聊天，不要用术语。

星语三秒生成。韩铮读完，沉默了一会儿，说：「写得比我快。」

「但是——」他指着其中一句，「『特征 A 对 CTR 提升显著。』我写过这句话，七年前，写在星潮第一版流量调控系统的文档里。它不知道，我为了验证这个『显著』，跑了四个月 A/B，压了三十个版本的线上实验。它一天实验都没跑过，凭什么说『显著』？」

林澈坐在他身边，一句话也接不上来。韩铮把椅子转过来，看着他说：「小林，你以后别学我。你要学会一边用它，一边信自己。两样缺一样，在这行都活不长。」他顿了顿，「转岗的事，我支持你。但你别指望着，换个部门就能躲过它。它不在部门里，它在整个行业里。」

他沉默了一会儿，又说：「我入行那年，公司还在人工出价，我的第一个任务，是把竞价价格表整理成 Excel。后来我学会 LR，学会 GBDT，学会深度学习——每一次我都以为是终点，结果都是起点。我以为这一次也一样，换个工具，还是那双手。直到我发现，新模型连参数都不需要我调了。」

「它不需要你调参，」林澈小声问，「那你还能做什么？」

韩铮没有回答。他转回屏幕，看着星语对话框里那篇「写得比我快」的报告，过了很久，才说：「所以才要学。学它怎么想，学它怎么错，学它哪些地方需要人。」他把椅子转回来，难得地笑了一下，「四十一岁学新东西，不丢人。丢人的是，明知道要变，还假装看不见。」

周五，林澈正式提交了《转岗意向确认书》。下午，苏晓约他在楼下咖啡店。

「初筛过了，恭喜。」苏晓开门见山，「但我劝你，先把期望值放低。」

「怎么？」

「实验室不是天堂。」苏晓搅着咖啡，「我进去三个月了，做的项目是『LLM 广告素材自动生成』——就是你入职那天跑的那个素材 A/B，再快十倍。老板的 KPI 是素材产出量，一天五千条。你知道这五千条里，有多少条是『人』写的吗？」

「多少？」

「零。」苏晓说，「我们也是流水线。只不过流水线的名字，叫『未来』。」

林澈沉默。苏晓看着他：「你转岗，到底是为了做研究，还是为了逃？」

林澈答不上来。他想起自己投的三次申请，想起初筛表上那个 A-，想起韩铮说的「它不在部门里，它在整个行业里」。

那天晚上，林澈回到家已经十一点了。他躺在床上睡不着，又爬起来，打开电脑，登上公司的数据后台——他入职时，人事给他开了一个权限，说是方便新人看自己的 KPI，他从来没有认真看过。

他先找到自己的名字。星语使用率：87%。效果增量：+2.1%。人效比排名：算法部第 3 名。

然后他找到韩铮。星语使用率：3%。效果增量：+11.4%。人效比排名：算法部第 21 名。

林澈盯着那两行数字，愣了。韩铮的效果增量，是他五倍。可系统里「效果增量」记的是「AI 带来的增量」，不是「人带来的增量」——韩铮手工优化的那部分，被系统记到了新模型头上。

他把页面往下拉，看到人效比排名公式的权重说明：星语使用率 40%，效果增量 30%，满意度 20%，工龄成本 10%。

工龄成本。他忽然明白，这个排名从来不是测谁干得好，是测谁便宜、谁好用、谁没有沉没成本。韩铮垫底，不是因为他不行，是因为他贵，因为他的经验在这个公式里，是一项负资产。

林澈的手指悬在「导出报表」的按钮上方，停了很久，最后还是关掉了页面。

手机亮了。韩铮发来一条消息：「小林，明天早上帮我看看，我那个 prompt 写的报告，哪句像 AI 写的？我想改成像我写的。」

林澈盯着那条消息，打了删，删了打，最后回了一个字：「好。」

他把手机扣在桌上，窗外的杭州城灯火通明。他忽然想起陈国栋临走时那句「我还得去接孩子」，又想起韩铮坐在星语对话框前的侧影。

他关灯躺下，闭上眼睛，眼前全是那张表。第十七行，他的名字，A-。旁边是韩铮，3%，第 21 名。

他不知道，下一个被叫进小会议室的人，会不会是他。

（第二章完）
